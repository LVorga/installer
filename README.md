# Installation du wiki LVorga

**macOS / Linux** — dans un terminal :

    curl -fsSL https://raw.githubusercontent.com/LVorga/installer/main/installer.sh | bash -s <ton-prénom>

**Windows** — dans PowerShell :

    irm https://raw.githubusercontent.com/LVorga/installer/main/installer.ps1 | iex

Il faut un compte GitHub invité dans l'organisation LVorga. Ces scripts ne contiennent aucune donnée de l'équipe.
